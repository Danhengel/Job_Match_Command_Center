MICROSOFT 365 SETUP

Connect your work account

The first connection requests only User.Read so we can verify Microsoft sign-in. Email, calendar, and OneDrive permissions will be requested separately later.

Privacy-first setup Authentication uses Microsoft OAuth with PKCE. Access tokens stay in this browser session and are not placed in the site source code.
  1. Open Microsoft Entra and go to App registrations → New registration.
  2. Name it CareerNavIQ Work Assistant.
  3. Under Authentication, add a Single-page application (SPA) redirect URI: https://careernaviq.com/.
  4. Copy the Application (client) ID from the Overview page and paste it below.
