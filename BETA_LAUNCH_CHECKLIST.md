# CareerOS Private Beta Launch Checklist

## Release gates

- [ ] PR checks pass: frontend, backend, migrations, and Docker
- [ ] Production secrets configured outside GitHub
- [ ] Database backup and restore tested
- [ ] Production migration completed
- [ ] HTTPS, CORS, HSTS, and security headers verified
- [ ] Scheduler enabled on exactly one application process
- [ ] Health endpoint and monitoring enabled

## Core journey

- [ ] Register and sign in
- [ ] Create a career profile
- [ ] Upload and analyze a résumé
- [ ] Search and save jobs
- [ ] Tailor application materials
- [ ] Track an application and next action
- [ ] Add a recruiter and interview
- [ ] Practice with Interview Coach
- [ ] Review Daily Brief and Weekly Report
- [ ] Configure and manually run automation

## Beta operations

- [ ] Invite a small initial group
- [ ] Publish known limitations
- [ ] Establish issue labels for bug, feedback, security, and accessibility
- [ ] Review errors and scheduler results daily
- [ ] Review user feedback weekly
- [ ] Do not add major features until launch-blocking issues are resolved

## Legal and support

- [ ] Review beta Terms and Privacy Notice with qualified counsel before commercial launch
- [ ] Replace repository issue tracker with a dedicated support channel before public launch
- [ ] Document data deletion and account closure procedures
