# Personal Work Assistant

CareerNavIQ has been reset and repurposed as a private personal work-assistant project.

## Current foundation
- `frontend/` — lightweight dashboard served by Node
- `backend/` — minimal FastAPI service ready for secure integrations

## Planned integrations
1. Microsoft sign-in
2. Outlook mail and calendar
3. OneDrive / permitted work files
4. ChatGPT / OpenAI API
5. Tasks, follow-ups, meeting preparation, and daily briefings
